# TutorTrap Demo Data

## Recommended concept

**Gravity & Falling Objects**

## Canonical truth

In the absence of air resistance, all objects fall with the same acceleration due to gravity, regardless of mass.

## Example trap

> A heavier object falls faster than a lighter object because gravity pulls harder on it.

## Example wrong reasoning

> I agree because heavier objects have more mass, so gravity pulls them harder, making them accelerate faster.

## Expected misconception

Greater gravitational force automatically means greater acceleration.

## Useful evidence

The learner connects increased force on the heavier object directly to increased acceleration without accounting for the increased inertia represented by mass in `F = ma`.

## Example targeted challenge

> Imagine a heavy ball and a light ball dropped together in a vacuum. If gravity pulls harder on the heavy ball, why does the heavier ball not gain a larger acceleration?

The exact wording should remain AI-generated in the live system; this is demo backup text only.

## Example recovery answer

> In a vacuum both objects fall at the same acceleration. The heavy object has a larger gravitational force, but it also has proportionally more mass, so using `a = F/m` the acceleration is the same.

## Why this example is strong

It produces a visible conceptual journey:

```text
“More force”
     ↓
“must mean more acceleration”
     ↓
Targeted scenario
     ↓
Recognize force and mass change together
     ↓
Same acceleration
```
